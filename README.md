# Proyecto analítico AquaLimpia

Tarea correspondiente a la Unidad 3 de la asignatura Ciencia de Datos.

## Descripción

Este proyecto desarrolla un análisis reproducible de los datos operacionales y ambientales proporcionados para el caso AquaLimpia. La entrega fue elaborada individualmente y utiliza Git y GitHub para mantener trazabilidad, control de versiones y una estructura preparada para revisión y colaboración futura.

## Objetivo

Analizar la información de las plantas de tratamiento, evaluar la calidad de los datos y generar resultados diferenciados para las áreas de Operaciones y Gestión Ambiental.

## Estructura del proyecto

- `analisis_aqualimpia.ipynb`: notebook principal del análisis.
- `codigo/`: funciones y scripts reutilizables.
- `datos/`: dataset original proporcionado para la tarea.
- `resultados/`: gráficos, reportes y objetos generados.
- `requirements.txt`: dependencias necesarias para reproducir el proyecto.
