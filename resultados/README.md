# Resultados del proyecto

Esta carpeta contiene las salidas generadas mediante la ejecución reproducible del notebook y los scripts del proyecto.

## Organización prevista

- `dashboard/`: visualizaciones y dashboard exploratorio.
- `reportes/`: salidas diferenciadas para Operaciones y Gestión Ambiental.
- `objetos/`: resultados serializados mediante Joblib cuando su reutilización esté justificada.

Los archivos generados no deben editarse manualmente. Si cambia el análisis, deben volver a producirse mediante el código correspondiente.
